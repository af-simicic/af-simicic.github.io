Gestión de procesos en Linux: systemd, cgroups y control de recursos

Domina systemd para gestionar servicios, controlar recursos con cgroups v2 y depurar procesos problemáticos sin perder el control de tu sistema.

systemd cgroups procesos rendimiento

systemd es el sistema de inicio y gestor de servicios estándar en la mayoría de distribuciones Linux modernas.

Units y targets en systemd

systemd organiza todo en unidades (units). Un servicio, un socket, un punto de montaje, un timer — todo es una unit.

# Ver todos los servicios activos
systemctl list-units --type=service --state=running

# Inspeccionar una unit
systemctl cat nginx.service

Control de recursos con cgroups v2

{{< nota >}} cgroups v2 es la versión unificada de control de grupos en el kernel Linux. {{< /nota >}}

# Limitar CPU y memoria a un servicio
# /etc/systemd/system/myapp.service
[Service]
CPUQuota=50%
MemoryMax=512M
