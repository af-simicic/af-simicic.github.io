Hardening SSH en Linux: de la configuración básica al bastionado real

Una guía técnica para reforzar la seguridad de OpenSSH en sistemas Linux de producción, cubriendo autenticación por clave, configuración de sshd_config y detección de intrusos.

SSH hardening OpenSSH Linux

SSH es la puerta de entrada a cualquier servidor Linux. Aunque su configuración por defecto es funcional, dista mucho de ser segura en un entorno de producción.

1. Deshabilitar autenticación por contraseña

{{< advertencia >}} Antes de deshabilitar la autenticación por contraseña, asegúrate de tener al menos una clave SSH válida en ~/.ssh/authorized_keys. {{< /advertencia >}}

# Editar configuración de SSH
sudo nano /etc/ssh/sshd_config

# Modificar estas directivas:
PasswordAuthentication no
PubkeyAuthentication yes

# Reiniciar el servicio
sudo systemctl restart sshd

2. Configurar Fail2ban

{{< tip >}} Fail2ban monitoriza los logs de autenticación y bloquea automáticamente IPs que superan un número de intentos fallidos. {{< /tip >}}

sudo apt install fail2ban -y

# /etc/fail2ban/jail.local
[sshd]
enabled = true
maxretry = 3
bantime = 3600
